# Cámara del Tesoro — Juego matemático

Juego web interactivo en español con 10 desafíos matemáticos para estudiantes de 13 a 17 años.

## Cómo jugar
Abre `index.html` en un navegador. Responde las preguntas para desbloquear los 10 mecanismos y abrir el cofre.

## Publicar con GitHub Pages
1. Sube la carpeta `camara-del-tesoro` completa a tu repositorio de GitHub.
2. En el repositorio, entra en **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)` y pulsa **Save**.
5. Cuando GitHub Pages termine de publicar, abre:
   `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/camara-del-tesoro/`

Si subes el contenido de esta carpeta a la raíz de un repositorio nuevo, la dirección será:
`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

No necesita instalar programas, librerías ni servidor.
